# Task Manager

**Task Manager** is a web application designed to help users manage their daily tasks and obligations. With Task Manager, users can easily organize tasks by priority and deadline, track their progress, and filter tasks by status.

## Features

- **Add tasks**: Create tasks with custom priority levels and deadlines.
- **Mark tasks as completed**: Track which tasks are finished.
- **Filter tasks by status**: Filter tasks by:
  - Active
  - Completed
  - High-priority
  - All tasks
- **Monitor progress**: Track and measure personal productivity by monitoring task completion.

## Technologies Used

- **Frontend**: 
  - HTML
  - CSS
  - JavaScript
- **Backend**:
  - Node.js
  - Express.js
- **Database**:
  - MySQL
  - Sequelize ORM
